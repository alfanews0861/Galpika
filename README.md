# 📰 గల్పిక (Galpika) - తెలుగు వ్యంగ్య వార్తా వేదిక
### Telugu Satirical News Application on Firebase / GCP

'గల్పిక' అనేది సమకాలీన రాజకీయ, సామాజిక, సినీ మరియు సాంకేతిక అంశాలపై సునిశిత హాస్యాన్ని, వ్యంగ్యాన్ని అందించే ఒక పూర్తి స్థాయి డిజిటల్ వ్యంగ్య వార్తా పోర్టల్. 

ఇది **Google Cloud Platform (GCP)** మరియు **Firebase** (Hosting, Cloud Functions, Firestore, Authentication) ఆర్కిటెక్చర్ ఆధారంగా రూపొందించబడింది.

---

## ✨ ప్రధాన విశేషాలు (Key Features)

1. **తెలుగు ఫాంట్లు & టైపోగ్రఫీ (Telugu Typography)**:
   - **హెడ్డింగ్స్ (Headings)**: **రామభద్ర (Ramabhadra)** ఫాంట్.
   - **బాడీ టెక్స్ట్ (Body & Normal Text)**: **మల్లన్న (Mallanna)** ఫాంట్.
   - ఫాంట్ సైజ్ అడ్జస్టర్ (`A-` / `A+`) రీడింగ్ మోడ్ తెలుగు పాఠకులకు అత్యంత అనుకూలంగా ఉంటుంది.

2. **డిజైన్ & బ్లూ థీమ్ (Theme & Design)**:
   - రాయల్ & నేవీ బ్లూ ప్రైమరీ థీమ్, క్లీన్ కార్డ్స్, లైవ్ సెటైర్ బులిటెన్ టిక్కర్, మొబైల్-ఫస్ట్ రెస్పాన్సివ్ లేఅవుట్.

3. **ఫుటర్ నావిగేషన్ (Bottom Footer Navigation - 4 Icons)**:
   - 🪶 **గల్పిక (Galpika)**: ప్రధాన వ్యంగ్య ప్రత్యేక కథనాలు, ఎడిటోరియల్ పంచ్, ట్రెండింగ్ కథనాలు.
   - 📍 **స్థానిక (Local)**: ఆంధ్రప్రదేశ్ & తెలంగాణ జిల్లాల వారీగా స్థానిక వ్యంగ్య కథనాలు (హైదరాబాద్, విజయవాడ, విశాఖపట్నం, వరంగల్, మొదలైనవి).
   - 📰 **వార్తలు (Vaarthalu)**: రాజకీయాలు, సినిమా, స్థానిక గోల, టెక్నాలజీ, క్రీడలు, వైరల్ విభాగాలు & లైవ్ సెర్చ్.
   - 👤 **ప్రొఫైల్ (Profile)**: గూగుల్ లాగిన్/లాగౌట్, విలేకరి డ్యాష్‌బోర్డ్, మరియు భారతీయ చట్టాల పాలసీ పేజీలు.

4. **యూజర్ రోల్స్ & పబ్లిషింగ్ (Roles & CMS)**:
   - **ప్రధాన అడ్మిన్ (Admin)**: ఏ వార్తనైనా రాయడం, ఎడిట్ చేయడం, పబ్లిష్ చేయడం, యూజర్ల రోల్స్ మేనేజ్ చేయడం.
   - **అనుమతి పొందిన రిపోర్టర్ (Authorized Reporter)**: కొత్త వ్యంగ్య వార్తలను చిత్రాలు, కేటగిరీ, జిల్లాల ట్యాగ్‌లతో ప్రచురించడం.
   - **పాఠకుడు (Reader)**: కథనాలు చదవడం, లైక్ చేయడం, వాట్సాప్ షేర్, మరియు బుక్‌మార్క్స్.

5. **భారతీయ చట్టాలు & డిజిటల్ మీడియా నియమావళి (Legal Compliances in Profile)**:
   - **వ్యంగ్య & పేరడీ నిరాకరణ (Satire Disclaimer)**: భారత రాజ్యాంగం అధికరణ 19(1)(a) మరియు ఐటీ చట్టం 2000 సెక్షన్ 79 ప్రకారం ఆర్టిస్టిక్ పేరడీ ప్రకటన.
   - **డిజిటల్ మీడియా నియమావళి (IT Rules 2021 Compliance)**: సమాచార సాంకేతిక నిబంధనలు 2021 ఎథిక్స్ కోడ్ అనుగుణ్యత.
   - **ఫిర్యాదుల పరిష్కార అధికారి (Grievance Officer)**: ఐటీ నిబంధనలు రూల్ 11 ప్రకారం 24 గంటల అక్నాలెడ్జ్‌మెంట్ & 15 రోజుల పరిష్కార విధివిధానాలు + ఆన్‌లైన్ ఫిర్యాదు ఫారమ్ (Grievance Ticket ID).
   - **గోప్యతా విధానం (Privacy Policy)**: డిజిటల్ వ్యక్తిగత డేటా రక్షణ చట్టం (DPDP Act 2023) అనుగుణ్యత.
   - **నిబంధనలు & షరతులు (Terms of Service)**.

6. **బ్యాకెండ్ & క్లౌడ్ ఫంక్షన్స్ (GCP / Firebase Functions)**:
   - `functions/index.js` లో వార్తల ధ్రువీకరణ, పబ్లిషింగ్ API, గ్రీవెన్స్ రిజిస్ట్రేషన్ మరియు రోల్స్ అసైన్‌మెంట్ ఫంక్షన్లు ఉన్నాయి.

## 🚀 ప్రాజెక్ట్ రన్ చేసే విధానం (How to Run Locally)

```bash

cd c:\Users\alfan\OneDrive\Desktop\Galpika
```

## 🌐 ఫైర్‌బేస్ / జీసీపీకి డిప్లాయ్ చేయడం (Firebase / GCP Deployment)

1. ఫైర్‌బేస్ కన్సోల్ (https://console.firebase.google.com) లో కొత్త ప్రాజెక్ట్ సృష్టించండి.
2. Authentication లో **Google Sign-In** ఎనేబుల్ చేయండి.
3. **Firestore Database** మరియు **Cloud Storage** లను ఆన్ చేయండి.
4. ప్రాజెక్ట్ క్రెడెన్షియల్స్‌ను `.env` ఫైల్‌లో ఉంచండి (చూడండి: `.env.example`).
5. డిప్లాయ్ చేయండి:
```bash
# Firebase CLI లాగిన్
firebase.cmd login

# ప్రాజెక్ట్ లింక్ చేయండి
firebase.cmd use your-firebase-project-id

# క్లౌడ్ ఫంక్షన్స్ డిప్లాయ్
firebase.cmd deploy --only functions

# వెబ్ హోస్టింగ్ డిప్లాయ్
npm.cmd run build
firebase.cmd deploy --only hosting,firestore:rules,storage:rules
```
